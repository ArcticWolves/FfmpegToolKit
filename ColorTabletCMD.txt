
В CMD команда color XY использует две шестнадцатеричные цифры:

X — цвет фона.
Y — цвет текста.

Например:  color 0E


| Код | Цвет                      |
| --: | ------------------------- |
|   0 | Чёрный                    |
|   1 | Синий                     |
|   2 | Зелёный                   |
|   3 | Бирюзовый (синий)         |               
|   4 | Красный                   |
|   5 | Фиолетовый                |
|   6 | Коричневый / тёмно-жёлтый |
|   7 | Светло-серый              |
|   8 | Тёмно-серый               |
|   9 | Ярко-синий                |
|   A | Ярко-зелёный              |
|   B | Ярко-бирюзовый            |
|   C | Ярко-красный              |
|   D | Ярко-фиолетовый           |
|   E | Жёлтый                    |
|   F | Белый                     |
