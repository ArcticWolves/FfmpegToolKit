FFmpeg ToolKit
==============

Консольная оболочка над FFmpeg для Windows: конвертация, редактирование,
извлечение, пакетная обработка и анализ медиафайлов через меню.
Запуск: FFmpegToolkit.bat


1. Установка FFmpeg
-------------------
FFmpeg в репозиторий не входит. Скачайте готовую сборку:

    https://github.com/BtbN/FFmpeg-Builds/releases

и скопируйте содержимое её папки bin (ffmpeg.exe, ffprobe.exe, ffplay.exe
и *.dll) в папку source\bin.

Какую сборку выбрать:
  ffmpeg-master-latest-win64-gpl-shared.zip   максимум возможностей:
      libx264, libx265, vidstab, фильтры eq, hqdn3d и др.
  ffmpeg-master-latest-win64-lgpl-shared.zip  без GPL-компонентов:
      ToolKit сам заменит их на доступные аналоги (OpenH264, Kvazaar,
      Media Foundation, NVENC/QSV/AMF, deshake, lutyuv, nlmeans...).

При первом запуске (и после замены ffmpeg.exe) ToolKit анализирует сборку:
какие энкодеры и фильтры есть, какие аппаратные энкодеры (NVIDIA NVENC,
Intel QSV, AMD AMF, Windows Media Foundation) реально работают на этом ПК.
Результат кэшируется в temp\caps. Пересканировать: пункт R главного меню.
Меню показывают только доступное, а по умолчанию выбирается лучший кодек.


2. Возможности
--------------
Конвертация    MP4 (H.264 / HEVC / AV1), MKV, WebM, MOV ProRes, OGV;
               GIF (оптимальная палитра), анимированный WebP, APNG;
               MP3, M4A (AAC/ALAC), Opus, OGG, FLAC, WAV;
               PNG, JPEG, WebP, AVIF, JPEG XL, TIFF, BMP, ICO, QOI,
               DPX, EXR, HDR, JPEG 2000, PAM, PBM/PGM/PPM.
Редактирование обрезка, склейка (с перекодированием и без), скорость, реверс,
               FPS, нарезка на сегменты, поворот (в т.ч. без перекодирования),
               масштаб, кадрирование (9:16, 1:1...), поля с размытым фоном,
               цветокоррекция и LUT, шумоподавление, резкость, деинтерлейсинг,
               fade, стабилизация (deshake / vidstab), водяной знак, текст и
               таймкод, субтитры (вшить или добавить дорожкой), нормализация
               громкости EBU R128, громкость, замена/добавление/микширование
               аудио, удаление аудио, шумоподавление звука.
Извлечение     аудио и видео без перекодирования, субтитры, кадры (интервал,
               ключевые, смена сцены), обложка, метаданные.
Инструменты    ремукс, удаление метаданных, VMAF/PSNR/SSIM, контакт-лист,
               волновая форма, спектрограмма, слайд-шоу, картинка + аудио,
               запись экрана, тестовое видео, субтитры из речи (Whisper).
Пакетная       все медиафайлы папки input по пресету.
Анализ         FFprobe (потоки, JSON, ключевые кадры, главы, громкость),
               информация о сборке, поиск и справка по кодекам/фильтрам.

Все команды FFmpeg записываются в temp\logs\history.log.


3. Папки
--------
input\       исходные файлы (меню выбора показывает медиафайлы отсюда)
output\      результаты
luts\        LUT-файлы (.cube, .3dl, .dat, .m3d, .csp)
models\      модели Whisper (ggml-*.bin) для распознавания речи
temp\        кэш, журналы, временные файлы (можно удалять)
source\bin\  FFmpeg

Структура кода:
FFmpegToolkit.bat        точка входа, главное меню
config.bat               пути, определение возможностей сборки
lib\common.bat           общие подпрограммы: ввод с проверкой, запуск
                         FFmpeg с журналом, экранирование путей для фильтров
lib\transcode.bat        общий движок: выходной файл -> кодеки -> запуск
modules\*.bat            разделы меню
modules\convert\         профили форматов; _image.bat и _anim.bat - движки
modules\edit\            операции редактирования
modules\tools\           инструменты
modules\codecs\          модули кодеков, по одному на энкодер
selectors\               диалоги выбора файла, кодека, LUT


4. Как добавить кодек
---------------------
Создайте modules\codecs\video\<имя энкодера>.bat (или audio\). Первая
строка - описание для меню:

    @rem @label H.264 - мой энкодер
    @echo off
    set "_q=23"
    if /i not "%~1"=="auto" call "%LIB%" :AskInt _q "Качество" 23 0 51
    set "VIDEO_CODEC=имя_энкодера"
    set "VIDEO_CODEC_OPTIONS=-crf %_q%"

Затем добавьте имя в нужные контейнеры в selectors\select_codec.bat
(:GetList) и в список _cfg_encoders в config.bat.


5. Лицензии
-----------
Скрипты ToolKit распространяются по лицензии MIT (файл LICENSE).

FFmpeg - отдельная программа со своей лицензией (source\LICENSE.txt):
  - LGPL-сборка: LGPL v2.1+/v3;
  - GPL-сборка: GPL v2+/v3 (из-за libx264, libx265, vidstab и др.).
ToolKit вызывает ffmpeg.exe как отдельную программу и не линкуется с ним,
поэтому лицензия скриптов не меняется при любой сборке.

Если вы распространяете ToolKit вместе с бинарниками FFmpeg, нужно
приложить текст лицензии FFmpeg и указать, где взять исходный код именно
этой сборки (для BtbN - ссылка на релиз и github.com/BtbN/FFmpeg-Builds).
Сборки с --enable-nonfree (например, с libfdk_aac) распространять нельзя;
ToolKit такие компоненты не использует.
Модели Whisper (whisper.cpp) распространяются по лицензии MIT.
